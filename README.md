## 📌 Огляд проєкту

**ContactFlow** — це сучасний, високопродуктивний клієнтський веб-застосунок для збереження та організації контактів. Застосунок розроблено виключно засобами **нативного (Vanilla) JavaScript ES6+**, **HTML5** та **CSS3**, без використання будь-яких сторонніх бібліотек чи фреймворків, відповідно до вимог методичних вказівок.

---

## ✨ Реалізований функціонал (Варіант 10)

1. **Додавання контактів з валідацією регулярними виразами (RegExp)**:
   - **Ім'я (ПІБ)**: обов'язкове поле (2–50 символів), підтримка українських та латинських літер, дефісів і апострофів.
   - **Номер телефону**: підтримка українського та міжнародного форматів (`+38 (0XX) XXX-XX-XX` або `0XXXXXXXXX`).
   - **Email**: перевірка формату адреси електронної пошти.
   - **Категорія**: вибір групи (👨‍👩‍👧‍👦 Родина, 💼 Робота, 🎉 Друзі, 📁 Інше).
   - **Візуальна індикація помилок**: червона підсвітка поля (`.is-invalid`), статусний індикатор та текстова підказка під полем; при валідному введенні — зелена індикація (`.is-valid`).
2. **Динамічне формування списку засобами DOM**:
   - Елементи списку не описані статично у розмітці, а генеруються через `document.createElement()`.
   - Зв'язок елементів інтерфейсу з об'єктами колекції через атрибут `data-id`.
   - **Групування за категоріями**: контакти розподіляються за окремими секціями («Родина», «Робота», «Друзі», «Інше») з індивідуальними лічильниками.
   - **Перемикання режимів відображення**: групований вигляд або суцільний список карток.
3. **Пошук у реальному часі (подія `input`)**:
   - Миттєва фільтрація контактів за ім'ям, номером телефону, email або нотатками.
   - Підсвічування знайденого фрагмента в тексті картки за допомогою регулярного виразу (`<mark class="search-highlight">`).
4. **Редагування контакту в модальному вікні**:
   - Відкриття модального діалогу із заповненими поточними даними.
   - Повторна валідація даних тими самими регулярними виразами.
   - Збереження змін без перезавантаження сторінки.
5. **Видалення записів із підтвердженням дії (Делегування подій)**:
   - Обробник події `click` підключений до спільного батьківського контейнера (`contactsContainer`) за принципом делегування через `event.target.closest()`.
   - Модальне вікно підтвердження перед фактичним видаленням.
6. **Збереження стану в `localStorage` (JSON)**:
   - Автоматична синхронізація колекції у форматі JSON (`JSON.stringify()` / `JSON.parse()`).
   - Початкові демонстраційні контакти при першому запуску, якщо локальне сховище порожнє.

## 🎁 Додатковий функціонал (на максимальну оцінку)

- 🌓 **Теми оформлення (Dark / Light mode)**: перемикач теми у шапці через CSS custom properties, автоматичне запам'ятовування вибору в `localStorage`.
- 🔔 **Toast-сповіщення**: анімовані спливаючі повідомлення про успішне додавання, редагування, видалення та копіювання з автозникненням.
- 📋 **Копіювання в буфер обміну (Clipboard API)**: швидке копіювання номеру або email в один клік з іконки.
- 📱 **Автоматичне маскування телефону**: автоматичне форматування цифр у шаблон `+38 (0XX) XXX-XX-XX` під час введення.
- 💾 **Експорт та імпорт (File API)**: можливість експортувати всю базу контактів у файл `.json` (об'єкт `Blob`) та завантажити її назад через `FileReader`.

## 🚀 Локальний запуск

Застосунок є на 100% клієнтським і не потребує встановлення сервера, збирачів чи пакетів Node.js:

1. Відкрийте файл `index.html` у будь-якому сучасному веб-браузері (Google Chrome, Firefox, Safari, Edge).
2. Або запустіть у **Visual Studio Code** за допомогою розширення **Live Server**:
   - Клацніть правою кнопкою миші на `index.html` → обрати **«Open with Live Server»**.

## 🌐 Хостинг (GitHub Pages)

Проєкт підготовлено до автоматичного розгортання на **GitHub Pages**:

1. Створіть новий репозиторій на [GitHub](https://github.com/new), наприклад `contact-manager`.
2. Виконайте команди в терміналі проєкту:
   ```bash
   git remote add origin https://github.com/<YOUR_USERNAME>/contact-manager.git
   git branch -M main
   git push -u origin main
   ```
3. У репозиторії перейдіть в: **Settings** → **Pages** → розділ **Build and deployment**:
   - **Source**: оберіть **GitHub Actions** (налаштований воркфлоу `deploy.yml`) або **Deploy from a branch** (`main` / root).
4. За кілька секунд сайт буде доступний за посиланням:
   `https://<YOUR_USERNAME>.github.io/contact-manager/`
